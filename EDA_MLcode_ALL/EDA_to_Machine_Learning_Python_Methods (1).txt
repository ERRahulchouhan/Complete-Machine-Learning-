Detection: df.isnull().sum() df.isna().mean() * 100 df.notna().sum()

df[“city”].fillna(df[“city”].mode()[0]) df.ffill() df.bfill()

Scikit-learn imputation: from sklearn.impute import SimpleImputer,

Rule of thumb: - Mean: roughly symmetric numerical data without
influential outliers. - Median: skewed data or data with influential
outliers. - Mode / most_frequent: categorical values. - KNN or Iterative
imputation: when relationships among features can help. - Add missing
indicators when the fact that a value is missing may be informative. Fit
imputers on training data only to avoid data leakage.

8. OUTLIER DETECTION AND TREATMENT

IQR: Q1 = df[“age”].quantile(0.25) Q3 = df[“age”].quantile(0.75) IQR =
Q3 - Q1 lower = Q1 - 1.5 * IQR upper = Q3 + 1.5 * IQR outliers =
df[(df[“age”] < lower) | (df[“age”] > upper)]

Z-score: from scipy.stats import zscore z =
np.abs(zscore(df[“age”].dropna())) outlier_mask = z > 3

Other detection methods: - Modified Z-score (median absolute deviation /
MAD) - Percentile thresholds - Box plot: sns.boxplot(x=df[“age”]) -
Isolation Forest: IsolationForest() - Local Outlier Factor:
LocalOutlierFactor() - DBSCAN(): density-based clustering -
EllipticEnvelope(): robust covariance-based detection

Treatment: - Investigate and correct data-entry errors. - Remove records
only when justified: df[condition] - Cap values:
df[“age”].clip(lower=lower, upper=upper) - Winsorize:
scipy.stats.mstats.winsorize() - Transform:
np.log1p(df[“positive_column”]) - Use RobustScaler() when robust scaling
is appropriate.

Do not automatically delete every outlier; some are valid and
meaningful.

25. RECOMMENDED END-TO-END SCIKIT-LEARN STRUCTURE

from sklearn.compose import ColumnTransformer from sklearn.pipeline
import Pipeline from sklearn.impute import SimpleImputer from
sklearn.preprocessing import OneHotEncoder, StandardScaler from
sklearn.model_selection import train_test_split from sklearn.ensemble
import RandomForestClassifier from sklearn.metrics import
classification_report

X = df.drop(columns=[“target”]) y = df[“target”]

num_cols = X.select_dtypes(include=np.number).columns cat_cols =
X.select_dtypes(include=[“object”, “category”]).columns

numeric_pipeline = Pipeline(steps=[ (“imputer”,
SimpleImputer(strategy=“median”)), (“scaler”, StandardScaler())])

categorical_pipeline = Pipeline(steps=[ (“imputer”,
SimpleImputer(strategy=“most_frequent”)), (“encoder”,
OneHotEncoder(handle_unknown=“ignore”))])

preprocessor = ColumnTransformer(transformers=[ (“num”,
numeric_pipeline, num_cols), (“cat”, categorical_pipeline, cat_cols)])

model_pipeline = Pipeline(steps=[ (“preprocessor”, preprocessor),
(“model”, RandomForestClassifier(random_state=42))])

X_train, X_test, y_train, y_test = train_test_split( X, y,
test_size=0.2, stratify=y, random_state=42 )

model_pipeline.fit(X_train, y_train) predictions =
model_pipeline.predict(X_test) print(classification_report(y_test,
predictions))

This pipeline keeps preprocessing inside the model workflow and learns
imputation, scaling and encoding from training data only.

IMPORTANT PRACTICAL NOTES

1.  Split data before fitting preprocessing steps to prevent data
    leakage.
2.  Use Pipeline and ColumnTransformer for reproducible preprocessing.
3.  Do not remove outliers without understanding whether they are errors
    or legitimate observations.
4.  Do not use accuracy alone for imbalanced classification.
5.  Use a baseline model before complex models.
6.  Choose metrics based on the business objective.
7.  Use time-aware validation for time-dependent data.
8.  PCA is optional; it is not required for every ML project.
9.  Some methods require extra packages; install the relevant library.
10. Check your installed scikit-learn version because some API names and
    availability can vary by version.
